# 术语表

| 术语 | 说明 |
|---|---|
| SOC | 土壤有机碳含量，当前查表结果单位为 `g/kg`。 |
| CK | 相同施肥、相同土层、侵蚀 0cm 的参考记录。 |
| 施肥处理 | `F` 或 `UNF`，对应两套独立原始数据。 |
| 侵蚀程度 | 原始数据中的 0、10、20、30、40、50、60、70cm 处理等级。 |
| 土层键 | 原始数据使用的 10、25、35、45、55 数值索引。 |
| 土层厚度 | 当前土层的实际厚度；0-20cm 为 20cm，其余支持土层为 10cm。 |
| 土壤容重（BD） | 用于碳库换算的输入，单位为 `g/cm³`。 |
| 单层碳库 | 某一土层的碳储量，单位为 `kg C/m²`。 |
| 0-20cm 碳库 | 0-20cm 表层的碳库。 |
| 0-60cm 碳库 | 0-60cm 五个土层碳库之和。 |
| 碳密度 | 碳库除以土层厚度（米），单位为 `kg C/m³`。 |
| 静态差异 | 当前数据中的处理值与 CK 参考值之差。 |
| 折算代理 | 将静态差异按固定年数除得的参考值，不是逐年模型输出。 |
| 秸秆碳输入 | 按生物量、碳比例和还田比例估算的碳输入。 |
| 系统总碳输入 | 基础凋落物碳输入与秸秆碳输入之和。 |
| 辅助观测参数 | pH、含水量、黏粉粒和全氮；当前不参与核心计算。 |
| 算法版本 | 计算口径的版本标识，用于历史结果追溯。 |
| 数据库版本 | 本地历史和草稿数据结构的版本标识。 |
| JSON 导出版本 | 历史记录可移植文件结构的版本标识。 |
