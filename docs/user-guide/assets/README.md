# 说明书资源

## 目录约定

- `screenshots/`：可选的当前应用局部界面截图，默认不纳入正文。
- `diagrams/`：流程图、数据关系图和说明插图。
- `examples/`：脱敏后的示例参数、JSON 和报告片段。

## 命名约定

文件名使用小写英文和短横线，例如：

- `home-inputs.png`
- `home-result.png`
- `history-detail.png`
- `pdf-export-windows.png`

当前版本正文暂不引用界面截图。原始截图位于外部资源目录，只有在后续需要展示特定界面状态时，才应从当前源码运行结果中重新截取并裁剪后加入本目录。

## 资源要求

- 只使用当前版本应用截图。
- 截图不得包含真实 API Key、个人路径、真实姓名或未经授权的历史数据。
- 截图说明应解释操作目标，不描述源码实现。
- PDF 和 HTML 使用同一份资源文件。
