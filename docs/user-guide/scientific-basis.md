# 科学口径与附录

本章是用户说明书中的专业参考部分。它与项目的业务契约保持一致，用于解释数据、公式、比较基准和结果限制。

## 1. SOC 数据来源

SOC 不是由辅助观测参数回归得到，而是按以下三维键直接查询原始数据表：

```text
施肥处理 × 侵蚀程度 × 土层键 -> SOC (g/kg)
```

施肥处理为 `F` 和 `UNF`。两套数据已经分别记录施肥和未施肥条件，不能再次叠加额外施肥系数。

侵蚀程度支持 `0/10/20/30/40/50/60/70cm`。其中 0cm 是 CK 参考处理。

## 2. 土层键映射

| 土层键 | 实际土层 | 厚度 |
|---:|---|---:|
| 10 | 0-20cm | 20cm |
| 25 | 20-30cm | 10cm |
| 35 | 30-40cm | 10cm |
| 45 | 40-50cm | 10cm |
| 55 | 50-60cm | 10cm |

土层键是原始数据的索引，不是“从地表到该数值”的深度累计量。

## 3. 碳库换算

### 3.1 单层碳库

```text
carbonStorage = SOC(g/kg) × BD(g/cm³) × thickness(cm) / 100
```

结果单位为 `kg C/m²`。

### 3.2 碳密度

```text
carbonDensity = carbonStorage / thickness(m)
```

结果单位为 `kg C/m³`。

### 3.3 容重假设

当前应用使用一个统一容重输入换算当前土层和整个 0-60cm 剖面。不同土层的真实容重差异没有在当前版本中单独建模。

## 4. CK 和静态差异

### 4.1 CK 定义

CK 是：

```text
相同施肥处理 + 相同土层 + 侵蚀深度 0cm
```

因此，20-30cm 当前记录必须与 20-30cm 的 0cm CK 比较，不能与 0-20cm CK 比较。

### 4.2 当前土层碳库差

```text
currentLayerPool - sameLayerCkPool
```

差值为正表示当前碳库高于 CK，为负表示低于 CK。

### 4.3 SOC 损失率

```text
max(0, (sameLayerCkSoc - currentSoc) / sameLayerCkSoc × 100%)
```

当 CK SOC 小于或等于零时，应用不输出有效的分母计算结果。

## 5. 0-60cm 剖面

剖面评估使用 0-20、20-30、30-40、40-50、50-60cm 五层。当前剖面与 CK 剖面必须：

1. 从 0cm 开始。
2. 连续覆盖至 60cm。
3. 无重叠、无缺口。
4. 在 20cm 处有明确边界。
5. 使用相同土层划分。

0-20cm 碳库是第一层碳库；0-60cm 碳库是五层碳库之和。

## 6. 时间字段的解释边界

历史字段 `netChange_20yr`、`netChange_100yr` 和 `recoveryRate_annual` 是为兼容原始数据结构保留的名称。当前应用没有逐年末期值、时间序列或可复现的动态模型参数，因此：

- `netChange_20yr` 表示 0-60cm 当前剖面相对 CK 的静态差异。
- `netChange_100yr` 表示 0-20cm 当前表层相对 CK 的静态差异。
- `recoveryRate_annual` 表示 0-60cm 静态差异除以 20 的折算代理。

这些值不是 20 年或 100 年后的观测值，不是恢复趋势，也不是动态预测。

## 7. 秸秆还田情景

### 7.1 秸秆碳输入

```text
strawCarbonInput = biomass(kg/ha) × carbonRatio × returnRatio / 10000
```

### 7.2 系统总碳输入

```text
totalInput = litterCarbonInput + strawCarbonInput
```

应用使用 0.3、0.5、1.0 三个还田比例，分别对应 30%、50%、100%。情景结果表示管理输入估算，不代表 SOC 已经增加同样数值。

## 8. 辅助观测参数

pH、含水量、黏粉粒和全氮只作为辅助观测信息，当前不进入 SOC 查表、碳库换算、CK 比较或秸秆情景公式。

## 9. 图表的展示假设

- 雷达图将不同指标按固定区间归一化，只适合在同一张图中观察相对位置。
- 关联散点图展示数据分布，不拟合因果模型。
- 热力图使用颜色表达 SOC 高低，具体值仍应以数据或结果表为准。
- 碳库组成图基于分层碳库，而不是各层 SOC 浓度比例。

## 10. 算法、数据库和 JSON 版本

当前发布版本使用算法 `v2`、数据库 `v3` 和 JSON 导出版本 `v2`。

- 新计算记录写入当前算法版本。
- 数据库迁移只增加字段，不改写旧计算结果。
- 旧记录会保留旧算法版本，以便追溯。
- 从历史记录载入只恢复输入参数，重新计算使用当前算法。
- 不同算法版本的结果不应直接作横向科学结论。

## 11. 模型和数据限制

当前版本不提供：

- 真实逐年 SOC 变化曲线。
- 基于时间序列的恢复速度估计。
- 由 pH、含水量、黏粉粒或全氮训练得到的回归模型。
- 不同土层独立容重的完整剖面模型。
- 将秸秆碳输入直接转化为 SOC 增量的动态过程模型。

如需这些能力，应补充逐年观测数据、模型参数和独立验证方案，不能仅通过解释当前字段实现。
