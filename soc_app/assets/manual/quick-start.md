# 快速入门

本章帮助你用一次完整流程完成土壤有机碳评估。第一次使用时可以保留默认参数，先熟悉结果结构，再替换为自己的观测值。

## 1. 评估流程

```text
填写参数 -> 点击“计算” -> 阅读结果 -> 查看图表
    -> （可选）生成 AI 报告 -> 导出 PDF -> 查看历史记录
```

应用支持 Windows 和 Android。核心计算口径相同，PDF 在 Windows 上按桌面文件处理，在 Android 上通过系统分享。

## 2. 填写参数

在首页“计算”页填写或确认以下内容：

| 参数 | 第一次使用时怎么填 | 作用 |
|---|---|---|
| 施肥方式 | 选择“施肥”或“未施肥” | 决定使用哪套原始 SOC 数据 |
| 侵蚀程度 | 选择 0、10、20、30、40、50、60 或 70cm | 选择侵蚀处理记录 |
| 土层范围 | 选择 0-20cm、20-30cm、30-40cm、40-50cm 或 50-60cm | 选择当前土层记录 |
| 统一土壤容重 | 填写实测值；默认值可用于试算 | 用于碳库换算 |
| pH、含水量、黏粉粒、全氮 | 填写观测值或保留默认值 | 仅作辅助观测说明 |
| 秸秆生物量、碳比例、凋落物输入 | 填写管理情景参数或保留默认值 | 计算秸秆还田情景 |

土层范围是实际土层，不是“从地表累计到某个深度”。例如，`20-30cm` 表示 20 至 30cm 的 10cm 土层。

## 3. 执行计算

点击右下角“计算”。应用会先检查输入范围和数据键：

- 输入有效时，生成当前土层结果，并保存一条历史记录。
- 输入无效时，在“输入错误”区域列出原因，不会使用旧结果代替新输入。
- 计算过程中按钮会进入“计算中”状态，避免重复提交。

参数停止变化约 2 秒后会自动保存草稿。成功计算后，当前草稿会清理。

## 4. 阅读结果

计算结果按以下顺序阅读：

1. **SOC 含量**：当前施肥、侵蚀和土层组合对应的 SOC，单位为 `g/kg`。
2. **当前土层碳储量**：当前土层的碳库，单位为 `kg C/m²`。
3. **碳密度**：按土层厚度折算的碳密度，单位为 `kg C/m³`。
4. **当前土层相对 CK 碳库差**：当前土层碳库减同施肥、同土层、侵蚀 0cm CK 碳库，单位为 `kg C/m²`。
5. **当前土层差值/20 年（折算代理）**：上一项静态差值除以 20 的参考值，不是逐年预测。
6. **当前土层相对 CK 损失率**：当前土层 SOC 相对同层 CK 的损失百分比。

结果区还会显示 0-20cm 和 0-60cm 的剖面静态差异。它们使用完整剖面查表数据，不能理解成对未来年份的模拟。

## 5. 查看图表

切换底部“图表”页签，可以查看 8 类图表：

- 侵蚀：不同侵蚀程度下的 0-20cm SOC。
- 深度：不同土层的 SOC 垂直分布。
- 秸秆：30%、50%、100% 秸秆还田的碳输入情景。
- 评估：多个碳库指标的相对尺度展示。
- 组成：0-60cm 各土层碳库占比。
- 关联：侵蚀程度与 0-20cm SOC 的数据分布。
- 对比：当前侵蚀与同施肥 CK 的 SOC 分布。
- 热力：侵蚀程度 × 土层的 SOC 矩阵。

图表是当前数据的可视化，不会增加新的观测数据，也不提供动态预测。

## 6. 生成报告和保存结果

### 6.1 PDF

在已完成计算的首页点击 PDF 图标：

- Windows：生成应用本地 PDF，并可另存、打开或定位文件夹。
- Android：生成应用本地 PDF，然后打开系统分享面板。

应用会为该历史记录维护一份稳定命名的本地副本。分享或另存的副本不会替代这份应用副本。

### 6.2 AI 报告

首次使用 AI 前，进入“设置”填写服务商、接口地址、模型和 API Key。返回图表页后点击“生成报告”。报告会流式显示，支持取消和重新生成。

AI 报告只解释当前计算结果，不重新计算 SOC，也不能替代专业判断。

### 6.3 历史记录

点击首页右上角历史图标，可以查看、重命名、载入或删除记录。历史记录保存参数、结果、算法版本和可选的本地 PDF 关联。

## 7. 第一次使用时必须记住

1. CK 是相同施肥、相同土层、侵蚀 0cm 的参考记录。
2. pH、含水量、黏粉粒和全氮当前不参与 SOC 查表或碳库换算。
3. 20 年、100 年字段是静态 CK 差异或折算代理，不是真实时间序列预测。
4. 修改任何参数后，旧结果、图表、AI 报告和 PDF 都不应继续代表新参数。
