# 常见问题

## 为什么修改参数后旧结果消失了？

参数变化后，旧结果、图表、AI 报告和 PDF 可能不再对应当前参数。应用会主动清空旧结果，重新计算后才生成新的结果。

## 为什么 pH 改变后 SOC 没有变化？

pH 当前是辅助观测参数。SOC 直接按施肥方式、侵蚀程度和土层查表，不使用 pH 回归计算。

## 为什么含水量、黏粉粒和全氮也没有改变结果？

这三项与 pH 一样，当前只用于记录和解释，不进入核心 SOC 和碳库公式。

## 20 年和 100 年结果是真实预测吗？

不是。它们是当前处理相对于同施肥 CK 的静态差异和折算代理。原始资料没有逐年观测值或可复现动态模型。

## 为什么深层土层不能和表层 CK 比较？

CK 定义要求施肥方式和土层都相同。深层必须与相同深度的 0cm CK 比较，不能用 0-20cm 表层作为分母。

## 为什么图表没有逐年趋势图？

当前数据没有逐年时间序列。应用只展示有数据依据的侵蚀、深度、碳库、情景和矩阵关系，不把示意数组伪装成真实趋势。

## 为什么计算失败？

检查容重、pH、含水量、黏粉粒、全氮和秸秆参数范围，并确认施肥、侵蚀和土层选项有效。错误原因会显示在计算结果上方。

## 草稿会保存多久？

停止输入约 2 秒后自动保存，未完成草稿最多保留 7 天。成功计算或手动恢复默认参数后会清理草稿。

## 为什么启动时出现恢复草稿提示？

应用检测到上一次未完成的输入。选择“恢复”会载入参数；选择“忽略”会关闭本次提示，但草稿仍可在有效期内再次恢复。

## 为什么 AI 报告生成失败？

检查 API Key、接口地址、模型名称、网络连接和服务商权限。自定义服务商需要有效的 HTTP/HTTPS 地址；如果服务商要求 Key，则不能留空。

## AI 报告会使用哪些数据？

AI 会收到当前计算参数、结果、剖面静态差异和秸秆情景。pH 等辅助参数会作为解释信息发送，但提示词会明确它们不参与核心公式。

## AI 报告为什么可能只有半段？

网络中断、服务商空闲超时或用户取消都可能中止流式响应。半段内容不应当作完整报告，可以重新生成。

## 为什么 PDF 在 Android 上没有“另存为”？

Android 使用系统分享能力发送应用本地 PDF。Windows 提供打开文件、定位文件夹和另存副本等桌面操作。

## 为什么历史记录有 PDF 标记但文件打不开？

PDF 可能被系统文件管理器手动删除，或文件被其他程序占用。历史页会检测文件是否存在，并尝试清理失效关联。

## 删除历史记录会删除我另存的 PDF 吗？

不会。应用只管理应用私有 `SOC-Shield/report_pdfs/` 目录中的副本，用户另存到其他目录的文件不受影响。

## JSON 导入为什么失败？

检查文件是否为本软件导出的 JSON，版本是否受支持，文件是否超过 20MB，记录数是否超过 10000 条，以及记录结构是否完整。

## 导入 JSON 会带入原设备 PDF 吗？

不会。JSON 不包含本机绝对 PDF 路径和 PDF 二进制内容，只导入可移植的计算数据。

## 为什么历史记录显示不同算法版本？

算法升级后，旧记录仍要保留原始结果并标记旧版本。不同版本结果不建议直接横向比较；载入旧记录重新计算会使用当前算法。

## 为什么对比页的雷达图只有两条记录？

对比表最多支持 5 条记录，但当前雷达图只绘制选择顺序中的前两条。3-5 条记录时请以参数、结果和剖面表为准。

## 为什么不同算法版本时雷达图隐藏？

雷达图使用归一化展示。混合算法版本会降低可比性，因此应用隐藏雷达图，但仍保留表格供追溯。

## API Key 会写入 JSON 或 PDF 吗？

不会。API Key 保存在系统安全存储中，不导出到历史 JSON，也不写入 PDF。不要把 Key 手动添加到说明书或截图。

## Android 发布版无法联网怎么办？

确认设备网络可用，并确认发布包声明了 `INTERNET` 权限。调试版能联网不代表缺少权限的发布版也能联网。
